# 𓆩♛𓆪 PREMIUM TELEGRAM SMM BOT 𓆩♛𓆪

> **An Advanced, Fully Automated Social Media Marketing (SMM) Bot for Telegram.**
> *Built with Pyrogram, MongoDB, and AsyncIO for blazing fast performance.*

---

### 💻 1. Core Architecture
> 🚀 **Framework:** Pyrogram & AsyncIO
> 🗄️ **Database:** MongoDB Atlas (Motor)
> 🔗 **Provider Integration:** Direct SMM Panel API (v2)

### 💲 2. VIP Features Included
* **Auto Margin Calculator:** 🪙 Set your profit margin (e.g., 40%) and the bot will auto-update all service prices dynamically.
* **1-Click Admin Approval:** 🛒 Users upload UTR & Payment details -> Admin clicks `Approve` in Telegram -> Account gets auto-credited.
* **Step-by-Step UI:** 🧾 Interactive ordering system using `pyromod`. No complex commands for users!
* **Referral Engine:** 🎁 Built-in link generator. Auto credits the referrer upon new joins.
* **Order History:** ⏳ Users can check their past 5 transactions and costs directly in the bot.
